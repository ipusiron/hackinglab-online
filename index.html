ヘルプ Help

このサイトは「生成AIで作るセキュリティツール」プロジェクトで開発された教育向けツールを集約した、独学支援プラットフォームです。

このサイトの方針

  • ランク制・順位・バッジ・称号は、これからも実装しません。超初心者から初心者のうちは、他人と比べる必要がないと考えているからです。
  • 各ツールの本体はGitHub Pages（ipusiron.github.io/<ツール>/）に置いています。このサイトはツールを置き換えるのではなく、探すための索引と、学ぶための文脈に徹します。
  • 著者の書籍・連載とも行き来できます。本で読んだ手法をツールで確かめ、ツールから本の該当箇所へ戻れます。

サイトの使い方

  • ツール一覧：カテゴリー・進捗・検索から学習するツールを探せます。
  • 書籍・シリーズ：本やシリーズに関係するツールだけに絞り込めます。本のサポートページからのリンク（?book=）で自動的に絞り込まれます。Day番号でも検索できます。
  • 学習ダッシュボード：学習進度を可視化し、Xで共有できます。
  • 進捗はブラウザーごとに localStorage に保存されます。

This site is a self-learning platform built on educational tools created in the project "Security Tools with Generative AI".

Our approach

  • No ranking, scores, badges or titles — now or later. Beginners have no need to compare themselves with others.
  • Each tool itself lives on GitHub Pages (ipusiron.github.io/<tool>/). This site is an index and a layer of learning context, not a replacement for the tools.
  • It also links back and forth with the author's books and series: try a technique from a book here, and jump from a tool back to the relevant chapter.

How to use this site

  • Tools tab: browse tools by category, progress status, and search.
  • Books & series: narrow the list to tools related to a book or series. Links from a book's support page (?book=) apply the filter automatically. You can also search by Day number.
  • Dashboard tab: track your learning progress and share snapshots on X.
  • Your progress is stored per browser using localStorage.
